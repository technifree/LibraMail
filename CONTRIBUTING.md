# Contributing / Contribution

## English

1. Fork the repository and create a focused branch.
2. Do not include `data/`, mail files, credentials, logs or generated packages.
3. Run `./github.sh check` before committing.
4. Keep the French and English locale files in sync.
5. Describe observable behaviour and testing in the pull request.

## Français

1. Dupliquez le dépôt et créez une branche ciblée.
2. N'ajoutez jamais `data/`, des messages, identifiants, journaux ou paquets générés.
3. Lancez `./github.sh check` avant le commit.
4. Maintenez les traductions française et anglaise synchronisées.
5. Décrivez le comportement visible et les essais réalisés dans la demande de fusion.
